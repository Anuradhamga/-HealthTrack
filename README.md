# 🏥 HealthTrack – Personal Health Analytics Dashboard

A modern, responsive web-based health analytics dashboard designed to manage patient information, monitor vital signs, analyze health records, and visualize health trends.

🌐 **Live Demo:** https://anuradhamga.github.io/-HealthTrack/

---

## 📌 Project Overview

HealthTrack is a web-based healthcare management and analytics project developed using HTML5, CSS3, and JavaScript.

The application provides a simple dashboard for managing patient profiles, recording health measurements, monitoring Body Mass Index (BMI), and visualizing health-related data through interactive charts.

The project demonstrates the practical application of frontend web development, data visualization, and browser-based data storage in the healthcare technology domain.

## ✨ Key Features

- **Dashboard Overview** – View total patients, health records, average BMI, and recent records.
- **Patient Management** – Add, edit, delete, and manage patient profiles.
- **Health Record Management** – Record blood pressure, heart rate, temperature, weight, and height.
- **BMI Calculator** – Automatically calculate BMI and identify BMI categories.
- **Health Analytics** – Visualize health trends using interactive charts.
- **Date Filtering** – Filter health records by specific dates.
- **CSV Export** – Export health records as CSV files.
- **Printable Reports** – Generate printable health reports.
- **Data Persistence** – Store records in browser LocalStorage.
- **Responsive Interface** – User-friendly dashboard layout.

## 🚀 Getting Started

### Prerequisites

- A modern web browser.
- Visual Studio Code (recommended).
- Live Server extension (optional).

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Anuradhamga/-HealthTrack.git
   ```

2. Navigate to the project directory:

   ```bash
   cd -HealthTrack
   ```

3. Open the project in Visual Studio Code:

   ```bash
   code .
   ```

4. Open `index.html` using Live Server or your preferred browser.
